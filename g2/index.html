1. Introduction to Propositions

A proposition (or statement) is a declarative sentence that is either strictly True (T) or False (F), but not both. In mathematical logic, we represent these statements using propositional variables such as P, Q, R, and S.

For example:

  • P: "The sky is blue." (True proposition)
  • Q: "The number 5 is greater than 10." (False proposition)
  • R: "x + 2 = 5." (Not a proposition, since its truth value depends on the variable x)

By combining these simple propositions with logical operators, we can construct compound propositions and analyze complex statements programmatically.

2. Logical Operators Reference

Propositional logic utilizes symbols to represent operations. Below is a cheat sheet of the symbols and rules supported in LogicSphere:

  • Negation (¬ - NOT): Inverts the truth value of a proposition.
    Rule: ¬P is True if and only if P is False.
  • Conjunction (∧ - AND): Combines statements requiring both to be true.
    Rule: P ∧ Q is True only if both P and Q are True.
  • Disjunction (∨ - OR): Combines statements requiring at least one to be true.
    Rule: P ∨ Q is True if P is True, Q is True, or both.
  • Exclusive OR (⊕ - XOR): Combines statements requiring exactly one to be true.
    Rule: P ⊕ Q is True if P and Q have different truth values.
  • Conditional (→ - IMPLIES): Represents "If P, then Q".
    Rule: P → Q is False only when the premise P is True and the conclusion Q is False.
  • Biconditional (↔ - EQUIVALENT): Represents "P if and only if Q".
    Rule: P ↔ Q is True when P and Q share identical truth values.
3. Truth Table Construction

A truth table lists all possible combinations of truth values for input variables and tracks the step-by-step outcomes of compound formulas.

To build a truth table manually:

  • Calculate the number of rows: If an expression has n unique variables, the table contains 2n rows.
  • Write columns for each variable, listing combinations systematically (e.g. alternating T/F values).
  • Write columns for intermediate subexpressions (e.g. for P ∧ ¬Q, construct columns for P, Q, ¬Q, and then P ∧ ¬Q).
  • Evaluate the final column to find the output.

4. Classification & Core Logic Laws

Propositional statements are classified into three types based on their truth tables:

  • Tautology: A compound proposition that is always True, regardless of the truth values of its component variables. (e.g. Law of Excluded Middle: P ∨ ¬P).
  • Contradiction: A compound proposition that is always False. (e.g. P ∧ ¬P).
  • Contingency: An expression that is True for some combinations and False for others. (e.g. P ∧ Q).

Key Equivalence Laws:

  • De Morgan's Laws:
    ¬(P ∧ Q) ↔ (¬P ∨ ¬Q)
    ¬(P ∨ Q) ↔ (¬P ∧ ¬Q)
  • Double Negation: ¬(¬P) ↔ P
  • Distributive Laws:
    P ∧ (Q ∨ R) ↔ (P ∧ Q) ∨ (P ∧ R)
